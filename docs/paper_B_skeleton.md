# Word-Coverage Retrieval: Exploiting the Word-Level Decomposability of Answers for Conversational Memory

## 目标: SIGIR 2027 短文(4页)或 EMNLP Findings
## 定位: 方法类(检索信号设计), 论文A的姊妹篇

---

## 一句话主张

对话记忆中, 答案与问题的向量差在词级收敛为平均3.1个"答案独有词", 这些词与证据句的覆盖竞争判别力(98%配对胜率)远超一切句级信号; 基于这一分解, 我们构造双空间互证检索(256词级侦察×1024句级主通道, 信号去相关0.025), 在不引入任何LLM调用的前提下实现错题+6/对题+5的检索改善, 并绘制了词向量空间的完整结构地图(序结构/类别簇/情感价/说话人残差)。

---

## 骨架

### 1 Introduction
- 句级检索的粒度困境(证据在窗率84%封顶, 名次无法继续前移)
- 词级分解的发现(3.1词/98%/词空间无半球0.997)
- 贡献: ①词覆盖方程与判别 ②双空间互证检索(去相关0.025) ③词空间结构地图(月/周/数字/情感/说话人) ④零LLM全链实现

### 2 Method
2.1 答案独有词分解(离线分析: x-a=3.1词, 方向一致0.891)
2.2 双空间互证: 256词级侦察(问题词→原子句词对齐矩阵) × 1024主通道
2.3 信号去相关验证(0.025; 句级伪侦察对照=同源零增益)
2.4 词空间结构地图: 乱序对照法(月0.902/周0.925/数字/情感/类别100%归属/说话人残差78→81%)

### 3 Experiments
3.1 设置: LoCoMo-Refined 50错+50对配对对照 + 全量验证; 双嵌入
3.2 主结果表: 错题进25 +6, 对题进5 +5(无权衡); 对照句级伪侦察(0增益)证明信号源差异
3.3 分析: ①侦察与主信号去相关是增益前提 ②剂量平坦(1.5~6不敏感) ③适用边界(指代残缺句未解, 上限85/100)
3.4 结构地图详解(五项: 月循环序+乱序对照/星期/数字序/情感价/类别100%)

### 4 Related Work
ColBERT(token级交互, 需训练) / BM25(词面无语义) / HyDE(伪答案, LLM成本) — 我们的词覆盖+双侦察: 零训练零LLM零词表
**必引区分**: Post-Hoc Answer Attribution (arXiv 2024)——答案分解做事后归因(LLM辅助), 我们反转方向: 答案分解做事前检索信号, 且提供判别力量化(98%配对/92%限定域)

### 5 Conclusion
词级分解给了对话记忆检索第二个独立的信号源; 结构地图给了它坐标。
