## 项目结论：失败

作者对项目的裁定是：**失败**。事实账：

- 核心目标（零训练、纯规则把会话内证据排序推近 89%）未达成：turn 层在全部已知约束下
  封顶 65.6% 命中@5，且五条独立证据（判别式七连败、标签粒度定律、人口论证伪、
  核函数更换无效、几何解剖）证明这是该约束下的物理水位，不是工程问题。
- 端到端 70.5% 距离榜首 82.65 有 12 分差距；排序层 78.2 距对标口径 89% 差 10.3 个点，
  根因定位为嵌入判别力不足——唯一可行的突破路线（嵌入微调）在项目期内被冻结，未执行。
- 会话层零训练公式（89.8@5 / 97.8@15 / LoCoMo 97.3@1）是仅存的达标成果；
  其余产出为负结果、机理解剖与测量方法论。

仓库按结题原样归档，代码与文档不做美化。

## 核心方法

**两层架构**：会话定位（通用层，零训练）+ 会话内精排（本地层）。

最终公式（零训练会话层）：

```
score(会话) = max_{记录∈会话} cos( e_1024(问题), e_1024(记录) )
```

一条余弦、一个 max。同一批向量，聚合单位从"记录"换成"会话"，
margin 中位数从 −0.020 翻正到 +0.127，榜首命中率从 42% 到 97%。

turn 层排序器（本地训练档）：

```
Mem(q; M) = C( rank[ T( ρ_P( Φ(q, r) ) ) ] )
```

Φ = 交互特征族，ρ = 池内分位（序数化），T = lambdarank 五百树，
C = 排位→含金率校准曲线（折外严格单调）。

## 主要发现

1. 形态定律：聚合形态的选择大于模型的选择（会话 max 聚合 +18pp）。
2. 金抱团结构：答案是一个聚集体（金金 cos 0.76），相关是一片散沙（0.59），
   同会话内部依然成立（差 0.173）。
3. 四空间差异地图：答案是句级现象（记录级 AUC 0.915 > 上下文词级 0.885 >
   静态词级 0.651）。
4. 坐标系定律：序数 vs 绝对特征的优劣取决于金的跨题稳定性住在哪个坐标系。
5. 标签粒度定律：会话级标签训练 turn 级任务是毒药（−34pp）。
6. 噪声结构决定论：任务-噪声关系规律随基准噪声结构生灭；
   检验规律必须在头部条件（使用条件）下做。

负面结果同样入账（详见 docs/ 战役报告第五节）：判别式头部七连败、
词面家族系统性反向、白化崩溃、人口论证伪等——每条都是实测定论。
